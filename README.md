# Region-aware training-free few-shot classification of pulsar candidates

Code for the paper *"Few Labels Suffice: Region-Aware Training-Free Few-Shot
Classification of Pulsar Candidates"* (submitted to A&A Supplement Series).

A vetting filter for radio pulsar candidates that keeps a vision-language model
(Qwen2.5-VL-7B) frozen end to end: no gradient step, no fine-tuning, no parameter
update. It decomposes each diagnostic plot into its four physical panels
(frequency–phase, time–phase, DM curve, pulse profile), scores every attention
head independently on each panel against a support set of 10–100 labeled images,
selects heads on that per-panel evidence, and classifies by vote. On a held-out
stream of 8,611 FAST candidates the deployed filter removes 77% of the stream at
the default operating point, and 67% at 90% pulsar recall.

The method builds on [SAVs](https://github.com/chancharikmitra/SAVS) (Mitra et
al., 2024); the region-aware panel decomposition, per-panel head scoring, and
coverage-constrained selection introduced here are the contribution of this work.

## Repository layout

```
src/                    model loading, per-panel head-activation extraction
scripts/
  run_regionaware.py    core method: per-panel scoring → selection → routing → vote
  run_baseline.py       whole-image baseline (global SAVs scoring)
  offline_kh_sweep.py   offline (k, N) sweep from cached head activations
  run_single_panel*.py  single-panel / panel-combination ablations
  run_head_ablation.py  retained-head-count ablation
  score_granularity_ab.py
  metrics_util.py       F1/precision/recall/AP/recall@FPR
  build_*_data.py       dataset construction & train/query splits (per survey)
  extract_textinfo.py   per-candidate metadata (chi2, period, DM)
  summarize_results.py  results tables
config/
  panel_crop_coordinates.json   panel cropping geometry for FAST prepfold plots
paper_rep/              paper-specific analyses (ablation, failure modes,
                        held-out stream metrics, split audit)
RESULTS.md              full result tables
```

## Requirements

Python ≥ 3.10, PyTorch ≥ 2.0, transformers, numpy, Pillow, tqdm
(see `requirements.txt`; one A100-class GPU for feature extraction; all
evaluation is CPU-only from cached activations).

```bash
pip install -r requirements.txt
```

## Data

FAST candidate images are subject to the survey's data policy; requests for the
derived dataset used in the paper should be directed to the first author. The
panel-cropping geometry is provided in `config/panel_crop_coordinates.json`.
Public comparison sets used in the paper:

- MiraBest: https://github.com/b-a-porter/MiraBest
- HTRU1 (batched): https://as595.github.io/HTRU1/
- HTRU2: https://archive.ics.uci.edu/dataset/372/htru2

All scripts resolve data through the `/SAVS_DATA_ROOT` prefix. Either create a
symlink (`ln -s /your/data/root /SAVS_DATA_ROOT`) or batch-replace the prefix.

## Reproducing the paper

| Paper artifact | Command |
|---|---|
| Table 3 (headline results) | `python scripts/run_regionaware.py --data region_gpps --k 50 --num_heads 40 ...` |
| Table 4 (k × N grid) | `python scripts/offline_kh_sweep.py ...` |
| Table 6 (ablation) | `python paper_rep/ablation_region.py` |
| LOO head scoring | `python scripts/offline_kh_sweep.py --mode loo ...` |
| Table 7 + Figure 8 (held-out stream) | `python paper_rep/heldout_metrics.py` |
| Failure-mode analysis | `python paper_rep/failure_modes.py` |
| Split audit | `python paper_rep/audit_leak.py` |

`RESULTS.md` holds the full result tables generated by `summarize_results.py`.
